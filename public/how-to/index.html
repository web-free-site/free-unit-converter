How to convert units

  1. Choose a category tab (Distance, Mass, Temperature, etc.) or open a dedicated category page from the menu.
  2. Click the input unit in the left list and the output unit in the right list.
  3. Type a value in Input — the result appears in Output, or type in Output to convert backward.
  4. Use the round Swap button to exchange units and values.
  5. Adjust precision (4–12 significant digits) in the toolbar.
  6. For bespoke conversions, open Custom and set 1 A = factor B.
